# MATLAB betikleri

Her konunun MATLAB çözümleri, plan numarasıyla adlandırılmış klasörlerde tutulur
(`faz0/polinomlar.m` gibi). MATLAB R2026b ile yazılmıştır.

Sembolik komutlar (`syms`, `diff`, `int`, `dsolve`) için **Symbolic Math Toolbox** gerekir.
Toolbox'ın olmadığı durumlar için sayısal karşılıklar (`polyder`, `polyint`, `integral`, `ode45`)
de verilir.
