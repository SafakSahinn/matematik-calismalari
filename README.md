# Matematik Çalışmaları

Polinomlardan diferansiyel denklemlere uzanan, adım adım ilerleyen bir çalışma defteri.
Her konu üç katmanda işlenir:

1. **Kağıt-kalem:** konu anlatımı ve çözümlü örnekler (`notlar/`)
2. **İnteraktif grafik:** tarayıcıda açılan, kaydırıcılı sayfalar (`docs/`)
3. **MATLAB:** aynı soruların MATLAB çözümleri (`matlab/`)

🌐 **Site:** https://safaksahinn.github.io/matematik-calismalari/
